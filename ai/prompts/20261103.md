# Instrução

1. Criar o arquivo `UiState.kt` com os estados da tela: Carregando, Vazio, Erro e Sucesso
2. Definir a estrutura da `sealed interface UiState`, especificando quais estados devem ser `data object` e quais devem ser `data class`, assim como os dados que cada estado precisa armazenar
3. Identificar o local correto para criação do arquivo `UiState.kt`, respeitando a organização de pacotes e pastas já existente no projeto
4. Verificar a entidade utilizada pelo projeto e definir como ela deverá ser representada no estado `Sucesso`, considerando a lista de dados que será recebida
5. Verificar a versão do Kotlin utilizada e garantir que a estrutura proposta seja compatível com ela

# Restrição

Não gerar nenhum código e não modificar arquivos

# Saída

Gerar o planejamento passo a passo em arquivo `.md` na pasta `/ai/outputs`.
